# ShadowOS — First Preview Release

**Version:** 1.0 Preview  
**Status:** Early Development

Welcome to **ShadowOS**, a new browser-based operating system experience!

### ✨ What's New
- Fresh ShadowOS branding and identity.
- Modern desktop interface.
- Windows-style taskbar and Start menu.
- Built-in apps including Calculator, Notepad, Paint and Browser.
- File Explorer interface.
- Personalization settings.
- App Store for discovering and installing apps.
- Support for importing HTML applications.
- Experimental `.w13` app package support.

### 📦 App Installer
ShadowOS is designed to support apps built with:
- HTML
- CSS
- JavaScript

APK importing is experimental and does not currently provide native Android execution.

### 🚧 What's Coming Next
- Improved app installer.
- Custom ShadowOS app package format (`.w13`).
- More built-in applications.
- New icons and themes.
- Performance and stability improvements.
